# AGENTS

This file sets guidance for AI agents working on this project.

## Defaults
- Keep changes small and focused.
- Prefer clean, maintainable code over clever code.
- Do not touch unrelated files.
- Do not create, delete or modify .meta files.
- Do not explain your changes.

## Safety
- Never run desctuctive commands unless explisitly requested.
- Preserve existing user changes.

## Skills
- Skills are located in `Assets/Skills/` foldier.
- If you're asked to create new skill, create it in `Assets/Skills/` foldier.
- If you are not sure where to start, start from checking existing skills and see if they can help you.

## Code style
- Prefer `var` over explisit type declartion.

## Unity
- If you need to work on scenes, prefabs or assets prefer MCP over direct file editing.
